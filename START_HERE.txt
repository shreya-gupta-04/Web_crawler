  Problem: Port 5000 already in use
  Solution: Kill the process and restart
  $ lsof -i :5000
  $ kill -9 <PID>

  Problem: Module import errors
  Solution: Activate virtual environment
  $ source .venv/bin/activate

  Problem: Slow crawling
  Solution: Reduce delay parameter (try 0.5 seconds)

  Problem: No search results
  Solution: Crawl pages first, then search

  Problem: Database errors
  Solution: Delete database and restart
  $ rm crawler.db
  $ python3 app.py

  More help: See FAQ.md
